# regseq-facade-22: RegisterOf trait, access control types, and RegisterId

## Description

Implement the type-level register access control system: `RegisterOf`
trait, `ReadAccess`/`WriteAccess` marker traits, concrete access marker
types, and the `RegisterId` type for full-register operations.

These types are prerequisites for Mmio<T> register access methods
(regseq-facade-23) and the register_block! macro (regseq-macros-04).

## Implementation Notes

Add the following to `crates/regseq/src/registers.rs` (or a new
`register_traits.rs` if registers.rs exceeds 500 lines):

### Public API

```rust
/// Associates a register marker type with a register block and its access kind.
/// Per-register REG constants (RegisterId) are generated by register_block!
/// in each register's module, not carried on the trait.
pub trait RegisterOf<Block> {
    type Access;
}

/// Marker trait for register width types (u8, u16, u32).
pub trait RegWidth: Copy + Clone + Default + core::ops::BitAnd<Output = Self> + core::ops::BitOr<Output = Self> + core::ops::Not<Output = Self> {}

impl RegWidth for u8 {}
impl RegWidth for u16 {}
impl RegWidth for u32 {}

/// Marker: the register supports read operations.
pub trait ReadAccess {}

/// Marker: the register supports write operations.
pub trait WriteAccess {}

/// Read-only access kind.
pub struct ReadOnlyAccess;
impl ReadAccess for ReadOnlyAccess {}

/// Write-only access kind.
pub struct WriteOnlyAccess;
impl WriteAccess for WriteOnlyAccess {}

/// Read-write access kind.
pub struct ReadWriteAccess;
impl ReadAccess for ReadWriteAccess {}
impl WriteAccess for ReadWriteAccess {}

/// Identifies a full register for read/write operations (no field
/// masking). Each register module produces a `REG` constant of this
/// type.
#[derive(Copy, Clone)]
pub struct RegisterId<W, R> {
    _width: core::marker::PhantomData<W>,
    _reg: core::marker::PhantomData<R>,
}

impl<W, R> RegisterId<W, R> {
    pub const fn new() -> Self {
        Self {
            _width: core::marker::PhantomData,
            _reg: core::marker::PhantomData,
        }
    }
}
```

### Changes to existing types

- `ReadOnly<T, R>`, `WriteOnly<T, R>`, `ReadWrite<T, R>` remain as
  `#[repr(transparent)]` layout types. Do NOT remove their existing
  methods yet -- that happens in regseq-facade-23 after Mmio methods
  are in place.
- `Reserved<T>` is unchanged.

## Non-Goals

- No Mmio<T> register methods (regseq-facade-23).
- No removal of existing ReadOnly/WriteOnly/ReadWrite methods yet.
- No register_block! macro (regseq-macros-04).
- No RegisterOf trait impls (those are generated by register_block!).
