### Change A: diag-log call-site interception (`body_emit.rs` `call`)

Replace the `:1797-1799` fail-loud. In `call`, when `callee == CallCallee::Direct(inst)`
and `self.model.instance_intrinsic(*inst) == Some(IntrinsicKind::Log(level))`:

- Recover `level` (the `LogLevel`) → the §8.1 bracketed tag (`[ERROR] `/`[WARN] `/
  `[INFO] `/`[DEBUG] `).
- Build the `printf` call via Changes B–D (parse `args[0]`; map `args[1..]` operands;
  emit the C format string + arg list + the per-`%s` `&str` buffers).
- `target` is always `Some(t)` for a Log callee (unit return; `I-DiagLog-CallArity`); emit
  `<printf-emission> goto bb_<t>;` (no destination assignment — the return is unit).
  `target == None` on a Log callee → model corruption → `Unsupported` (defensive).
- **Pipeline-A (§8.5):** read `args` directly as the peeled flat operands. Never
  reconstruct a `LogArg`. The arity check `args.len() == 1 + N` (N = placeholder count)
  is the bridge's invariant; on mismatch fail loud (`Unsupported` — a bridge-invariant
  violation, not a representable shape).

Keep the existing non-diag-log `Direct` / `Indirect` paths unchanged. (Recognition stays
the durable model fact: `instance_intrinsic` is keyed by instance identity; an `Indirect`
callee can never satisfy the predicate.)

### Change B: the §26.7-subset format-template parser + template-bytes reader (`body_emit.rs`)

A backend-local parser (the backend has **no** access to the driver's `format.rs`, and
the model carries no parsed template). Two parts:

1. **Read the template text.** `args[0]` is an `Operand::Constant(cid)`. Resolve
   `model.consts` → `Const::Aggregate([reloc, len])` over `Ty::Ref(Str)`; resolve `reloc`
   → `Const::Reloc(iref)` → `resolve_reloc(model, iref)` → the `ConstMemoryStatic`
   instance → its `InstanceKind::Static{ init: Some(bytes_cid) }` → `Const::Bytes(bytes)`
   → take `bytes[0..len]`'s `Byte::Value` → UTF-8 `String` (mirrors `peel.rs:191-227`,
   but through the model). D6 guarantees a literal; any other shape → `Unsupported`
   (defensive; a bridged model never hits it).
2. **Parse** the text into an ordered sequence of segments: `Literal(&str)` |
   `Placeholder(Modifier)`. The `Modifier` is either `None` (the default `{}`) or a hex
   modifier carrying the **flag tuple** `{ upper: bool, alternate: bool, width: u32 }`
   (mirroring the bridge's `FormatSpecifier::{Hex, HexUpper, HexFormatted{ fill, width,
   alternate, upper }}` at `format.rs:204-238`) — **not** a fixed 7-variant enum. Rules:
   `{{`/`}}` → literal `{`/`}` (consume two chars, emit one literal char; **not** a
   placeholder); `{` … `}` → a placeholder, its inner text selecting the `Modifier`;
   embedded `\n` is ordinary literal text; an empty template yields one (possibly empty)
   `Literal` and zero placeholders. **Malformed braces** (an unclosed `{`, a stray
   unescaped `}`) → `Unsupported` (defensive — the bridge already rejects them,
   `format.rs` `unclosed_brace_rejected:356` / `stray_close_brace_rejected:381`, so a
   bridged model never carries one).

   **Accepted hex forms = the bridge's actual set (`parse_hex_spec`, `format.rs:204-238`),
   which is a SUPERSET of §26.7's table.** §26.7 (`spec.md:12829-12846`) lists `:x`/`:X`/
   `:#x`/`:#X`/`:08x`/`:#010x` and declares the subset "closed at the leading set", **but
   HEAD's bridge also accepts the uppercase-padded `:08X` and `:#010X`** (`format.rs:213,
   216`; test `uppercase_alternate_and_zero_padded_forms_accepted:457`). The backend must
   lower **whatever the bridge produces**, so the parser accepts the bridge's eight forms —
   `{x, X}` × `{plain, #-alternate, 08-zero-padded, #010-zero-padded-alternate}` — into the
   `{upper, alternate, width}` tuple. Any inner text outside this set (positional/named/
   other widths/`:?`/`:b`/`:o`/`:p`/precision) → `Unsupported` (the bridge rejected it;
   defensive). **This §26.7-vs-bridge drift is NOT task e's to reconcile** (widening §26.7's
   table or tightening the bridge is a separate doc/bridge decision — flag it, do not fix
   it here); task e only ensures the backend is robust to the bridge's real output.

The number of `Placeholder` segments **must** equal `args.len() - 1` (the
`I-DiagLog-CallArity` parity); on mismatch fail loud.

### Change C: the §8.2 / §26.7 per-arg C **specifier + cast** mapping (`body_emit.rs`)

A mapping `(Modifier, operand_ty) -> (specifier: String, cast: String)` — **both** the C
conversion AND the **value cast**, because C varargs need the *argument value's* type to
match the conversion after default promotion, not merely matching format text (a `u64`
passed to `%llu` as a 32-bit value is UB / a silent miscompute). The diag-log path gates
on the **§26.4-admissible set** (`Bool` / `Uint(U8..U64)` / `Int(I8..I64)` / `Ref(Str)`)
and dispatches:

- **Default (`Modifier::None`):** reuse the existing `body_emit::printf_spec` helper
  (`body_emit.rs:1941-1957`) **only for the admissible numeric arms** — `Ty::Bool` /
  `Int(I8|I16|I32)` → `("%d", "(int)")`; `Uint(U8|U16|U32)` → `("%u", "(unsigned)")`;
  `Uint(U64)` → `("%llu", "(unsigned long long)")`; `Int(I64)` → `("%lld",
  "(long long)")` — and `Ref(Str, _)` → `("%s", "")` (no numeric cast — the §8.3 `&str`
  materialisation, Change D) **separately**. `printf_spec` is **broader than §8.2** (it
  also matches `Char` → `%u`, `Isize`/`Usize`, and an unknown-`Ty` fallback to `%lld`,
  none §26.4-admissible) and does **not** encode the `%s` / `Unsupported` arms — so reuse
  it **behind an admissible-type whitelist**: any operand `Ty` outside the admissible set
  (incl. `Char`/`Isize`/`Usize`) → `Unsupported`, **not** a delegation to `printf_spec`'s
  broader arms.
- **Hex modifiers** (integer-width operands only; §26.8 D2 / `validation.rs:193-207`
  guarantee this — a `Bool` / `&str` under a hex modifier → `Unsupported` defensively):
  build the conversion from the `{upper, alternate, width}` tuple AND **cast the value to
  the unsigned integer of its SOURCE width, then to the varargs width**:
  - the conversion letter `x` (lower) / `X` (upper); the C `#` flag for `alternate`; the
    `0<width>` zero-pad for `width > 0`;
  - **the `ll` length modifier is MANDATORY for 64-bit operands** (`Uint(U64)` /
    `Int(I64)`), inserted **immediately before the conversion letter**: `{:08x}` on a
    `u64` → `%08llx`; `{:#010X}` on a `u64` → `%#010llX`. For ≤32-bit no length modifier.
  - **the cast is two-step: `(varargs-unsigned)(unsigned-of-source-width)(<op>)`** — `%x`/
    `%X` read `unsigned`/`unsigned long long`, and the **source-width reinterpret is
    load-bearing for signed `i8`/`i16`** so a negative value renders Rust's
    source-width two's-complement, NOT a sign-extended 32-bit pattern:
    - `Int(I8)` → `(unsigned)(uint8_t)(<op>)` (so `-1i8` → `ff`, **not** `ffffffff`);
    - `Int(I16)` → `(unsigned)(uint16_t)(<op>)` (so `-1i16` → `ffff`);
    - `Int(I32)` → `(unsigned)(uint32_t)(<op>)` (so `-1i32` → `ffffffff`);
    - `Uint(U8|U16|U32)` → `(unsigned)(<op>)` (already unsigned of ≤32-bit; zero-extends);
    - `Uint(U64)` / `Int(I64)` → `(unsigned long long)(<op>)` (64→64, bit-preserving;
      `-1i64` → `ffffffffffffffff`).
    Concretely (`W` = `width` digits when `width>0`, else empty; `H` = `ll` iff 64-bit):
    specifier `%(#?)(0W?)(H)(x|X)`, cast as above.

**Known C-vs-Rust edge (document, do not "fix"):** C's `%#x` of `0` prints `0` (the `#`
flag adds `0x` only for nonzero), whereas Rust's `{:#x}` of `0` prints `0x0`. This is an
inherent `printf`-`#`-flag property; §26.7's modifier maps to the C `#` flag directly. Do
not add a special-case workaround (it is the only such divergence and a vanishing edge —
logging the hex of a literal `0`); record it only in the conditional §8.2 clarification.

### Change D: `printf` emission, the `&str` strategies & the C-string escaper (`body_emit.rs`)

Assemble the call:

- **Format string** (one C string literal): `"[LEVEL] "` ++ (walk the parsed segments:
  a `Literal` → its bytes **C-escaped** with literal `%` → `%%`; a `Placeholder(m)` → the
  Change-C **specifier** for `(m, ty_of(args[i+1]))`) ++ `"\n"`. The escaper renders a byte
  run as a C string-literal body: `"` → `\"`, `\` → `\\`, `\n`→`\n`, `\t`→`\t`,
  `\r`→`\r`, other non-printable / non-ASCII bytes → octal `\nnn` (3-digit, to avoid
  greedy `\x` runs); printable ASCII verbatim; **and literal `%` → `%%`** (only in the
  format string — a `%` inside an emitted `&str` *value* literal is not doubled, since it
  is a `printf` *argument*, not the format).
- **Argument list** (in placeholder order, one C arg per `Placeholder`): **every numeric
  arg is wrapped in the Change-C `cast`** for its `(modifier, ty)` — NOT just bool. The
  cast is mandatory: matching the format text is insufficient for C varargs (a `u64` `%llu`
  arg passed as a 32-bit value, or a signed-hex arg without an unsigned cast, is UB / a
  silent miscompute). Mirrors the existing panic-formatter pattern (`printf_spec` +
  `body_emit.rs:1940`).
  - **Numeric, default** (`Uint`/`Int`/`Bool`): `<cast>(<operand_expr>)` — e.g.
    `(unsigned long long)(<op>)` for a `u64`, `(long long)(...)` for an `i64`,
    `(int)(...)` for a `bool` / `i32`, `(unsigned)(...)` for a `u32`.
  - **Numeric, hex**: the Change-C **two-step** cast
    `<varargs-unsigned>(<unsigned-of-source-width>)(<operand_expr>)` — e.g.
    `(unsigned)(uint8_t)(...)` for an `i8`, `(unsigned long long)(...)` for a `u64` — so a
    negative `i8`/`i16` renders its source-width two's-complement, not a sign-extended
    32-bit pattern.
  - **`Ty::Ref(Str)` — §8.3 dispatch on the operand's provenance** (no numeric cast; the
    materialised `char*`/`const char*` is passed):
    - **Static literal** (the operand is an `Operand::Constant` resolving to the `&str`
      carrier `Aggregate([Reloc→CMS, Uint(len)])` over `Ty::Ref(Str)`): read the CMS bytes
      `[0..len]` (Change B's reader) and emit them as a **C string literal** (the escaper,
      no `%`-doubling — it is an argument); pass that literal. No buffer.
    - **Non-static** (any other `&str` operand — an `Operand::Copy/Move(place)`, e.g. a
      runtime-borrowed / sliced `&str`): emit a **per-`%s`-site** stack buffer. With
      `<op>` the lowered fat-pointer expression (`.data` = `const uint8_t *`, `.len` =
      `size_t`) and `CAP` a backend constant (**pick 256**, the §8.3 floor):
      ```c
      char _logstr<k>[256];
      {
          size_t _n = (<op>.len) < (256 - 1) ? (<op>.len) : (256 - 1);
          memcpy(_logstr<k>, (<op>.data), _n);
          _logstr<k>[_n] = '\0';
      }
      ```
      then pass `_logstr<k>`. `<k>` is a per-call-site, per-`%s`-site counter →
      **independent** buffers (two `&str` args each get their own). Truncation is
      unconditional + deterministic per §8.3 (copy `min(len, cap-1)`, NUL at
      `min(len, cap-1)`, no marker, no panic, no over-read/over-write).

- **Statement shape.** Emit the buffer preludes (the `char _logstr…[256]; { … }` blocks)
  then the `printf(<fmt>, <args>…);`, all as the terminator's C text, followed by
  `goto bb_<target>;`. (The buffers are block-scoped at the call site, per §8.3
  "per-`%s`-site buffer".) When there are zero `&str` non-static args, no buffer prelude
  is emitted (just the `printf` + `goto`).

The static-vs-non-static discriminator is purely structural: an `Operand::Constant`
resolving to the `&str` carrier → static; anything else of type `&str` → non-static. (No
provenance tracing beyond the operand form — matches §8.3's "traces to a static string
literal Constant".)

### Change E: activate `--bless` (`codegen-coverage-runner` `main.rs` + `pipeline.rs`)

Replace the inert `--bless` branch (`main.rs:108-117`). When `--bless` is set, for each
discovered fixture: run stage-1 (acquire) + stage-2 (emit), then **write the emitted
`.c` to `fixture.golden_c`** (creating/overwriting it), and **skip the stage-3 snapshot
comparison** (there is nothing to compare against — bless *is* the regeneration). Then
**still run stages 4–6** (compile/run/behavioral) in **report mode** so the author sees
whether the freshly-blessed emit compiles, runs, and matches the **hand-authored**
`expected.stdout` (printing the actual stdout on a miss, so a new fixture's
`expected.stdout` can be authored from observed-then-verified output — a deliberate human
action). Print a per-fixture "blessed `golden.c` (N bytes)" line.

**Honesty invariant (binding):** `--bless` writes **only `golden.c`** (the determinism /
snapshot oracle). It **never** writes `expected.stdout` or `expected.stderr` — the

### Change F: pipeline entry-symbol resolution (`codegen-coverage-runner` `pipeline.rs` + expose `naming::sanitize`)

## Acceptance Criteria

1. **Call-site interception** (Change A, `body_emit.rs`): the `task e` fail-loud is
   replaced; a `Direct` callee with `instance_intrinsic == Some(Log(level))` emits the §8
   `printf` (no C definition for the marked item — already enforced) then `goto
   bb_<target>` with no destination assignment; a `None` target on a Log callee fails
   loud; the flat peeled args are read directly (no `LogArg` reconstruction, §8.5);
   placeholder count == `args.len()-1` or fail loud.
2. **Format-template parser + CMS read** (Change B): the template text is read from
   `args[0]`'s `ConstMemoryStatic` through `model.consts` + `resolve_reloc` (not the
   bridge cache); the parser accepts the **bridge's actual set** — `{}` + the **eight** hex
   forms `{x,X}`×`{plain,#,08,#010}` (incl. the uppercase-padded `:08X`/`:#010X` beyond
   §26.7's table, represented as a `{upper, alternate, width}` tuple), `{{`/`}}`, embedded
   `\n`, empty template; an out-of-subset shape **or a malformed brace** → `Unsupported`;
   the §26.7-vs-bridge drift is flagged (not reconciled).
3. **Per-arg specifier + cast** (Change C): the diag-log path gates on the §26.4-admissible
   set and reuses `printf_spec` **only for the admissible numeric arms** (`%d`/`(int)`,
   `%u`/`(unsigned)`, `%llu`/`(unsigned long long)`, `%lld`/`(long long)`), maps
   `Ref(Str)`→`%s` separately, and rejects any **non-admissible `Ty` (incl.
   `Char`/`Isize`/`Usize`) → `Unsupported`** (the whitelist gates `printf_spec`, which is
   broader). **The `ll` length modifier is inserted for `U64`/`I64` hex AND every numeric
   arg is cast** (matching format text alone is UB for C varargs); signed hex uses the
   **two-step source-width cast** (`i8`→`(unsigned)(uint8_t)`, …, `i64`→`(unsigned long
   long)`) so a negative value renders Rust's source-width two's-complement; a hex modifier
   on a non-integer → `Unsupported`.
4. **`printf` emission + `&str` strategies** (Change D): the C format string is `[LEVEL] `
   ++ the interleaved literal/specifier walk ++ `\n`, with literal `%`→`%%` (format
   string only) and correct C-escaping; **every numeric arg is wrapped in its Change-C
   cast** (not just bool); a **static-literal** `&str` emits a direct C string literal from
   the CMS bytes; a **non-static** `&str` emits a per-`%s`-site independent stack buffer
   (cap 256, `min(len, cap-1)` `memcpy`, `\0` at `min(len, cap-1)`, no marker, no
   over-read/over-write) — the §8.3 normative contract; the static/non-static split is
   decided by the operand form.
5. **`--bless` activation** (Change E, runner): `--bless` regenerates **only** `golden.c`
   from the stage-2 emit and runs stages 4–6 in report mode; it **never** writes
   `expected.stdout`/`expected.stderr` (the behavioral oracle is hand-authored); the
   non-`--bless` run is unchanged.
6. **Entry-symbol resolution** (Change F, runner): the pipeline resolves `manifest.entry`
   (a rendered-path suffix) to the backend-emitted symbol via `naming::sanitize`
   (exposed) before `generate_main_c`, mirroring `fn_cname`; the first on-disk fixture
