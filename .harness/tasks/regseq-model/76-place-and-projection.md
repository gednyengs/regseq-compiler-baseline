# regseq-model-76: Place and PlaceElem (P1a-DS-11)

## Description

Implement the `Place` and `PlaceElem` IR data shapes per
`spec.md` §19.1: the `Place` struct (head local + projection
chain) and the closed 6-variant `PlaceElem` enum (`Deref`,
`Field(FieldIdx, TyId)`, `Index(LocalId)`, `ConstantIndex { .. }`,
`Subslice { .. }`, `Downcast(VariantIdx)`). Document the
two structural invariants (I-Deref-first and
I-Downcast-followed-by-Field) and reproduce the §19.4
type-narrowing rules table **as documentation only** -- the
walk-implementation that enforces them lives in P1a-VAL-01
(regseq-model-83).

`Place` is body-local content (no top-level interner; no
`PlaceId`). The projection chain is stored as `Box<[PlaceElem]>`
matching rustc's `&'tcx List<PlaceElem<'tcx>>` slab semantics
modulo `'tcx`-arena interning per `spec.md:6709-6718`.

## Implementation Notes

Create a new module `crates/regseq-model/src/place.rs`
(re-exported from `lib.rs`).

### Public API -- Place

Per `spec.md:6574-6589`:

```rust
/// A typed lvalue: head local plus a chain of projections.
///
/// `Place` is body-local content: it appears inside a body's
/// statements / terminators, not in any top-level interner
/// table. Equality is structural over `(local, projection)`.
pub struct Place {
    /// The head local. Must resolve to a `LocalDecl` entry in
    /// the enclosing body's `local_decls` (stage-11 vocabulary).
    pub local: LocalId,

    /// The projection chain, applied left-to-right. Empty for
    /// a bare local (e.g., `Place::from(_3)`). Owned slab
    /// (no interning); see §19.2.
    pub projection: Box<[PlaceElem]>,
}
```

### Public API -- PlaceElem (closed 6-variant)

Per `spec.md:6595-6692`:

```rust
/// Closed projection vocabulary (6 variants in source-
/// declaration order). The bridge raises a diagnostic if a
/// rustc `PlaceElem<'tcx>` outside this set appears (see
/// §15.1 rejections for `OpaqueCast` and `UnwrapUnsafeBinder`).
pub enum PlaceElem {
    /// Pointer load: `*head` / `*projected_value`. Subject to
    /// the I-Deref-first invariant (§19.3).
    Deref,

    /// Field projection. The `FieldIdx` indexes into the
    /// projected type's field list, dispatched by predecessor
    /// `Ty`. The inline `TyId` is the post-narrow field type,
    /// stored redundantly with what the layout would yield.
    /// Cheap O(1) narrowing during the projection walk.
    Field(FieldIdx, TyId),

    /// Array / slice index by a runtime-computed value held
    /// in a separate local. The `LocalId` payload is the
    /// head of a separate `Place::from(local)` that produces
    /// the index value. **Note:** `Index` carries a `LocalId`,
    /// not an `Operand` -- so `Place` has no circular
    /// dependency on stage-6 `Operand`.
    Index(LocalId),

    /// Constant offset into a fixed-length array or slice,
    /// generated by slice/array patterns. See spec.md:6634-6661
    /// for the per-pattern combinations.
    ConstantIndex { offset: u64, min_length: u64, from_end: bool },

    /// Sub-slice projection. See spec.md:6664-6677 for the
    /// per-pattern combinations.
    Subslice { from: u64, to: u64, from_end: bool },

    /// Downcast to a specific enum variant (selecting the
    /// active variant for the next `Field` projection).
    /// Subject to the I-Downcast-followed-by-Field invariant
    /// (§19.3). The `VariantIdx` is the source-order variant
    /// index; rustc's `Option<Symbol>` variant-name slot is
    /// dropped per D-5-1.3 -- recovered render-side from the
    /// enum layout's `VariantLayout.name` per §11.1 / §19.8.
    Downcast(VariantIdx),
}
```

### Structural invariants (documentation only)

Per `spec.md:6727-6755` -- both invariants are **doc-only** at
the data-shape layer; enforcement lands in P1a-VAL-01:

- **I-Deref-first.** If `place.projection[i]` is `Deref`, then
  `i == 0`. Compound chains like `Field.Deref` cannot occur in
  our input (rustc's PostCleanup phase forbids them).
- **I-Downcast-followed-by-Field.** If
  `place.projection[i]` is `Downcast(_)`, then `i <
  projection.len() - 1` AND `projection[i+1]` is `Field(_, _)`.

Document both invariants in the type-level doc comment for
`PlaceElem` and (as a forward-pointer to `PlaceElem::Deref` /
`PlaceElem::Downcast`) reference the validator task ID where
enforcement lands (P1a-VAL-01 / regseq-model-83).

### Type-narrowing rules table (documentation only)

Reproduce the §19.4 type-narrowing table verbatim in a

`spec.md:6764-6773`. The 8-row table covers each `PlaceElem`

### Conventions

- **`Place` equality is structural** over `(local, projection)`
  per `spec.md:6707`. Derive `PartialEq, Eq, Hash`.
- **`Place` does not participate in cross-build identity**
  (F4 / F4-2 in §16) per `spec.md:6720-6725`.
- **`Place::from(local)`-style helper.** A `From<LocalId> for
  Place` impl that produces `Place { local, projection:
  Box::new([]) }` is conventional (cited at `spec.md:6586`).
  Provide it as part of the public API.
- **`projection: Box<[PlaceElem]>` storage** per
  `spec.md:6709-6718`. Eight bytes leaner than
  `Vec<PlaceElem>` (no capacity slot) and conveys the
  immutable-after-construction contract.
- **Equality / Hash on `Box<[PlaceElem]>`** comes for free via
  `derive` -- the underlying `[PlaceElem]` slice already
  implements `PartialEq` / `Hash` element-wise.
- **`PlaceElem::Field(FieldIdx, TyId)`** stores the
  post-narrow field type **redundantly** with what the layout
  would yield, for O(1) narrowing per `spec.md:6620-6622`.
- **`PlaceElem::Index(LocalId)`** carries a `LocalId`, not an
  `Operand`, to avoid circular dependency on regseq-model-77 /
  P1a-DS-12a per `spec.md:6628-6630`.
- **`PlaceElem::Downcast(VariantIdx)`** drops rustc's
  `Option<Symbol>` slot per D-5-1.3 (`spec.md:6685-6691`).
- **Serde**: `Place`, `PlaceElem` contain `LocalId` / `TyId` /
  `FieldIdx` / `VariantIdx` typed-IDs and `u64` / `bool`
  primitives. Serde derives are admissible. Use
  `#[derive(Serialize, Deserialize)]`. Adjacently-tagged enum
  format `#[serde(tag = "kind", content = "data")]` (or the
  project's existing tagging convention) on `PlaceElem`; mirror
  the convention used by other body-local enums in the project.
- **Derive `Clone, Debug, PartialEq, Eq, Hash`** on `Place`
  and `PlaceElem`.
- **Doc comments mandatory** on every public type, variant,
  field per `SESSION.md` Coding Conventions. The two structural
  invariants and the §19.4 type-narrowing reference appear in
  doc comments per the requirement above.

## Test Plan

**Test organization**: `unit-in-src` -- tests live in
`crates/regseq-model/src/place.rs` `#[cfg(test)] mod tests`.

Coverage requirements (every public type / variant / accessor
exercised at least once per `SESSION.md` Testing Requirements):

1. **Bare-local `Place` construction.** Build
   `Place { local: LocalId(0), projection: Box::new([]) }`;
   assert `local == LocalId(0)` and
   `projection.is_empty()`.
2. **`From<LocalId>` for `Place`.** Build via
   `Place::from(LocalId(3))`; assert equivalent to manual
   construction with empty projection.
3. **`PlaceElem::Deref` construction.** Build
   `PlaceElem::Deref`; assert clone equality.
4. **`PlaceElem::Field` construction.** Build with
   `(FieldIdx(2), TyId(7))`; assert field accessors / pattern
   match on the tuple variant.
5. **`PlaceElem::Index` construction.** Build with
   `LocalId(4)`; assert single-field tuple-variant access.
6. **`PlaceElem::ConstantIndex` -- positive `from_end: false`.**
   Build with `{ offset: 0, min_length: 4, from_end: false }`;
   assert each field reads back the construction value.
7. **`PlaceElem::ConstantIndex` -- positive `from_end: true`.**
   Build with `{ offset: 1, min_length: 4, from_end: true }`;
   assert distinctness from item-6 build.
8. **`PlaceElem::Subslice` -- positive `from_end: false`.**
   Build with `{ from: 0, to: 3, from_end: false }`; assert.
9. **`PlaceElem::Subslice` -- positive `from_end: true`.**
   Build with `{ from: 1, to: 0, from_end: true }`; assert
   distinctness from item-8.
10. **`PlaceElem::Downcast` construction.** Build with
    `VariantIdx(2)`; assert single-field tuple variant.
11. **All 6 variants pairwise distinct.** Build one of each;
    assert all `(6 choose 2) = 15` pairs are inequal.
12. **`Place` with non-trivial projection.** Build
    `Place { local: LocalId(1), projection: Box::new([
       PlaceElem::Deref,
       PlaceElem::Field(FieldIdx(0), TyId(7)),
    ]) }`; assert structural reads.
13. **`Place` equality -- identical.** Two structurally
    identical `Place` values are `==` and hash-equal.
14. **`Place` equality -- differing projection.** Two `Place`
    values with the same `local` but differing `projection` are
    inequal.
15. **`Place` equality -- differing local.** Two `Place` values
    with identical `projection` but differing `local` are
    inequal.
16. **`Place` Hash -- HashSet round-trip.** Insert two distinct
    `Place` values into a `HashSet`; assert size 2; insert a
    clone; assert size still 2.
17. **`PlaceElem` Hash discrimination.** Insert one of each of
    the 6 variants into a `HashSet`; assert size 6.
18. **Box<[PlaceElem]> equality semantics.** Build two `Place`
    values whose `projection` slabs have identical contents but
    were constructed independently; assert `==`.
19. **Empty projection slab.** A `Place` with
    `projection: Box::new([])` round-trips clone + equality.
20. **Serde round-trip -- `Place` (bare local).** Round-trip
    via `serde_json::to_string` / `from_str`; assert `==`.
21. **Serde round-trip -- `Place` (non-trivial projection).**
22. **Serde round-trip -- `PlaceElem` (each variant).** Cover
    all 6 variants.
23. **`PlaceElem::Field` redundant `TyId` carry.** Construct
    two `Field` projections that share `(FieldIdx,
    TyId(different))`; assert inequality. (Verifies the inline
    `TyId` is part of equality.)
24. **`PlaceElem::Downcast(VariantIdx)` distinguishes per
    variant.** Build with `VariantIdx(0)` and `VariantIdx(1)`;
    assert inequality.
25. **Doc-comment mention of structural invariants.** Manual
    inspection or `cargo doc --no-deps -p regseq-model`
    smoke-build (best-effort) confirms the type-level doc
    comments mention I-Deref-first + I-Downcast-followed-by-
    Field as forward-pointers to P1a-VAL-01. (This is a
    soft test; the existence of the documentation matters for
    Codex review.)

`cargo test -p regseq-model` passes.
