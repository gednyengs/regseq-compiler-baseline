# regseq-model-24: Place and Projection

## Description

Implement the `Place` and `Projection` types that represent memory
locations in the CFG-based IR. A place is a local variable plus an
optional chain of projections (dereference, field access, indexing, etc.).

### Public API

```rust
// ir/place.rs

/// A memory location: a local variable plus an optional chain of projections.
#[derive(Clone, Eq, PartialEq, Hash, Debug, Serialize, Deserialize)]
pub struct Place {
    pub local: LocalId,
    pub projection: Vec<Projection>,
}

/// A single projection step applied to a place.
#[derive(Clone, Eq, PartialEq, Hash, Debug, Serialize, Deserialize)]
#[serde(tag = "kind", content = "data")]
pub enum Projection {
    /// Dereference a pointer or reference.
    Deref,

    /// Access a field of a struct, tuple, or enum variant.
    Field {
        index: u32,
        name: Option<Symbol>,
        ty: RegseqType,
    },

    /// Runtime index into an array or slice.
    Index(LocalId),

    /// Compile-time index generated by array/slice patterns.
    ConstantIndex {
        offset: u64,
        min_length: u64,
        from_end: bool,
    },

    /// Slice subrange generated by slice patterns.
    Subslice {
        from: u64,
        to: u64,
        from_end: bool,
    },

    /// Select an enum variant before accessing its fields.
    Downcast {
        name: Option<Symbol>,
        variant_index: u32,
    },
}
```

### Conventions

- `Place` with an empty `projection` vec is just the local itself.
- `Field` carries `name` and `ty` directly so consumers don't need
  type-definition lookups.
- `name` is `Option<Symbol>` because tuple struct fields are positional.
- Serde: adjacently-tagged enum for `Projection`. `Place` is a plain struct.
- `Symbol` fields will not serialize standalone (they are opaque handles).
  For now, derive Serialize/Deserialize on the types assuming they will be
  serialized within a model-level context that resolves symbols. If this
  conflicts with Symbol not implementing Serialize, use `#[serde(skip)]`
  on Symbol fields and add a TODO for model-level serialization.

## Non-Goals

- No Operand or Rvalue types (regseq-model-25, 26).
- No IR construction logic.

## Test Plan

- Construct a bare local place: `Place { local: LocalId(0), projection: vec![] }`.
- Construct a field access: `Place { local: LocalId(1), projection: vec![Projection::Deref, Projection::Field { index: 0, name: Some(sym), ty: Scalar(U32) }] }`.
- Construct each of the 6 Projection variants.
- Equality: two identical Places are equal; changing one projection element makes them unequal.
- `cargo test -p regseq-model` passes.
