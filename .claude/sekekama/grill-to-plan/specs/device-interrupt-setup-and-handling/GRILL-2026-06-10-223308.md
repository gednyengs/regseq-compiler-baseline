# GRILL — device-interrupt-setup-and-handling (construct #6)

## Context

**Problem/goal.** Lock every implementation-blocking decision in the eval-side design analysis
(`docs/constructs/device-interrupt-setup-and-handling/`, Codex arc foundation SOUND-WITH-CHANGES →
diff APPROVE, 2026-06-10) so `draft-prd` → `draft-plan` → compiler handoff can proceed with no further
questions. The construct: declare a device's interrupt line(s) (`Interrupt` resource), bind an authored
handler (`#[rseq::isr]` → `IrqResult`), compiler-managed line lifecycle
(register/enable/disable/deregister, conditional vector allocation), `[interrupt.<id>]` L2 binding.

**Consumers.** The compiler harness (implements bridge/model/backends per the PRD/plan), the eval
Tier-2 campaigns (trace whitelists, conformance), the taxonomy feedback channel.

**Non-goals.** `allocate_vectors`/MSI-X lowering, `Option`/array LOWERING, `DeferWork` lowering, PM
slots (class-G), affinity, Windows/FreeBSD backends, the Synchronization construct, device-class
(serial-uart/NIM) choreography.

**Hard constraints.** Frozen taxonomy surface (Step-11 `verified`, zero promotions; boundaries B1–B4)
is not re-litigated. No compiler work before PRD+plan; compiler work sequences after
`unit/spec-convergence-pl011` and `backend/zephyr-c-e1000` land. generic_c is the frozen oracle.

**Testing approach & seams.** Tier-1 generic-c: deterministic golden traces (the placement contract
made observable) + bridge unit tests + negative set; Tier-2 QEMU pl011-linux/pl011-zephyr (then
e1000-linux) with trace-whitelist + conformance citations. Single-vCPU campaign pin (D11).

**Grounding.** `spec-derived`: taxonomy organized spec + canonical page + Step-11 evidence/gap-log.
`code-confirmed`: four refined corpora + cross-OS reconciliations; compiler state (domain_attr,
backends, capability table, L2Binder, pl011-full-spec fixture + `platform.toml:21-25`).
`design-intended`: the five eval docs. User decisions this session are `design-intended` unless noted.

## Decisions

**D01 — Registration placement: init preamble, all targets.** `register_handler` is emitted in the
device-lifecycle init preamble (after register→create→associate, ordered per D14), deregister in the
deinit postamble. Linux's at-open idiom is not adopted; the probe-to-remove line-hold is a recorded,
whitelisted behavioral delta vs stock (visible in `/proc/interrupts`). *Rejected:* per-target
placement (OS-conditional logic; Linux registration would have no home pre-device-class); defer
(blocks the trunk). *Evidence:* Zephyr `IRQ_CONNECT` is build-time (cannot move to open);
taxonomy + fixture contract ("registered before `init` runs"). Provenance: spec-derived placement,
user-ratified. Confidence: high. Impact: lifecycle synthesis ordering; whitelist entry (S09).
Test: golden-trace order (C01); Tier-2 `/proc/interrupts` window check. Surfaces: S04, S09.

**D02 — Line-enable safe point: after `on_init` returns `Ok`.** Registration happens line-disabled
(Linux `IRQF_NO_AUTOEN` — G-INT-04 generalized; Zephyr `IRQ_CONNECT` without the stock immediate
`irq_enable`); `enable` is emitted only after `on_init` succeeds; on `Err` it never runs. Closes the
early-firing hazard (stale boot causes vs uninitialized state; E1000 ICR read destroys the cause).
Constraint accepted: authored `on_init` bodies cannot rely on live interrupts (neither corpus device
does). *Rejected:* end-of-preamble enable (hazard returns); author-controlled marker (surface
extension). Provenance: design-intended, user-ratified. Confidence: high. Impact: backend emission
split + ordering facts (D14). Test: C01 trace order `IRQ register … on_init … IRQ enable`; fire-before-
enable inert in generic-c. Surfaces: S04, S07.

**D03 — Zephyr static-connect deregister: NEW capability-disposition kind.** Row
`(zephyr, v4.4.0, dt, static_connect, interrupt.register_handler.deregister)` gets a new
"operation structurally absent on this registration form" disposition kind (AbsentOperation-style),
NOT a reuse of lifecycle `AbsentDispatch` (whose semantics are "dispatch condition cannot occur" —
here deinit occurs, the OS lacks the op). Same four-artifact audited rendering (RSEQ-ABSENT-SLOT-style
audit comment at the postamble position, conformance-report entry, RSEQ-CONFORMANCE log line, eval
whitelist citation of the CAP row ID). Deinit still emits `irq_disable`; post-deinit state
"connected-but-masked" is stated in the conformance report + whitelist. Widens the capability table's
domain beyond lifecycle slots — explicit PRD work item. *Rejected:* reuse AbsentDispatch (semantic
broadening by precedent); leave kind to harness (the kind IS the semantic decision). Provenance:
design-intended, user-ratified. Confidence: high. Impact: `capability.rs` schema + zephyr_c wiring.
Test: conformance JSON asserts the row; Tier-2 whitelist cites it. Surfaces: S06, S09.

**D04 — `DeferWork`: emit-time rejection this phase.** Frontend/IR accept the full 3-arm enum; any
reachable `DeferWork` on a backend without deferred-work lowering fails at emit with a loud
`EmitError` naming `deferred-work-item-scheduling` (linux_c I06 loud-error precedent). Semantics
unchanged from the frozen surface; this is a phase limitation, not a narrowing. `DeferWork` ≠ Linux
`IRQ_WAKE_THREAD` only (E1000 NAPI schedules and returns `IRQ_HANDLED`). *Rejected:* frontend
rejection (surface reads narrowed; rework later). Provenance: design-intended, user-ratified.
Confidence: high. Test: recognition unit test for the arm; negative emit fixture. Surfaces: S03.

**D05 — `IRQF_SHARED` is L2-driven.** linux_c emits `IRQF_SHARED` iff L2 `shared = true`. L2 `shared`
is the physical board fact (QEMU-virt PL011 `false` per fixture `platform.toml:25`; E1000 INTx
`true`) and drives the `NotHandled`-arm discipline check. Generated PL011 therefore differs from
stock (which requests `IRQF_SHARED` unconditionally) — recorded stock-parity delta; a wrong
`shared=false` fails loudly at `request_irq` (-EBUSY), which is correct behavior for a wrong platform
file. *Rejected:* stock-parity-always (L2 decorative, masks bad platform files); override knob
(machinery without a witness). Provenance: design-intended, user-ratified. Confidence: medium-high.
Test: golden flags per fixture `shared` value; E1000 leg exercises `true`. Surfaces: S05, S04.

**D06 — `Option<Interrupt>`/`[Interrupt; N]`: recognize + frontend-check now, lowering EmitError.**
Bridge recognizes all three forms; the multi-resource frontend checks get real fixtures; lowering of
Option/array is a loud `EmitError` this phase (same discipline as D04). *Rejected:* single-form-only
(three frozen checks untestable; rework later). Provenance: design-intended, user-ratified.
Confidence: high. Test: negative/recognition fixtures (C06). Surfaces: S01, S02, S08.

**D07 — generic-c fire: synchronous.** `regseq_irq_fire(line)` invokes the registered wrapper inline
from harness `main` between scenario steps; no host threads. Deterministic exact-interleaving goldens;
explicitly supersedes PLAN §1's "host thread" note (record as PLAN amendment note); Tier-1 stays weak
for OS-integration constructs either way. *Rejected:* host thread (nondeterministic goldens); both-now
(unneeded). Provenance: design-intended, user-ratified. Confidence: high. Surfaces: S07.

**D08 — `id` always required on `#[rseq::interrupt]`.** No inference of the L2 join key; uniform
authoring. A tightening deviation from the taxonomy (which requires `id` only for multi-resource) —
recorded as taxonomy feedback. Bare `#[rseq::isr]` HANDLER auto-bind stays per taxonomy. *Rejected:*
taxonomy-faithful optional-id + field-name inference rule. Provenance: design-intended, user-ratified.
Confidence: high. Test: frontend error fixture for missing id. Surfaces: S01, S05.

**D09 — linux_c uses the manual pair.** `request_irq(IRQF_NO_AUTOEN | flags)` in the preamble,
`free_irq` in the deinit postamble; not `devm_request_irq` (devres teardown is invisible post-remove,
muddying the postamble trace contract; leak risk moot for generated code; matches stock corpus shape).
Provenance: design-intended, user-ratified. Confidence: high. Test: C01 trace symmetry; Linux
conformance reports `delivered` for deregister (contrast with D03's Zephyr row). Surfaces: S04.

**D10 — trigger_type/trigger_polarity: validation-first.** Keys live in the L2 schema with canonical
spellings (`level|edge`; `active_high|active_low|rising|falling` — fixture's `"high"` normalized);
generic-c traces them; NO backend emits trigger flags this slice (DT is authoritative on both current
targets; flags can fight DT, -EBUSY on shared-line mismatch). DT cross-check = future work. `priority`
likewise: Zephyr `IRQ_CONNECT` arg, ignored on Linux (G-INT-07). *Rejected:* emit `IRQF_TRIGGER_*` now.
Provenance: design-intended, user-ratified. Confidence: high. Surfaces: S05.

**D11 — ISR↔mainline exclusion: accept + document as phase limitation.** No exclusion primitive
exists pre-Synchronization; wrappers do not auto-acquire locks (frozen bound-handler discipline
honored). Mitigations: Tier-2 campaigns pinned single-vCPU QEMU; first-slice fixtures keep ISR-shared
state minimal; recorded as an **arrival obligation on the Synchronization construct** (its design must
provide the ISR-side lock kind; cf. G-INT-01 `IrqSpinLock`). SMP campaigns before Synchronization are
out of contract. *Rejected:* compiler-emitted auto-lock (violates ratified discipline, front-runs
Synchronization); blocking on Synchronization (contradicts locked build order). Provenance:
design-intended, user-ratified. Confidence: medium (accepted risk, explicitly bounded). Surfaces:
S02, S04, S09.

**D12 — Registration failure follows the lifecycle preamble-failure contract.** `request_irq` failure
in the preamble fails init before `on_init` (so `on_init_failure` does not run); already-acquired
resource preambles unwind in reverse per the lifecycle construct's existing semantics (precedent:
`map_region` failure surfaces in lifecycle init, register-access design §4.3). Zephyr static connect
cannot fail at runtime (build-time); generic-c hook returns void (model may trace a failure scenario
later — not this slice). Provenance: design-intended (derived from existing contracts, not asked).
Confidence: high. Test: future negative scenario; not a first-slice golden. Surfaces: S04.

**D13 — Zero handlers on a non-optional `Interrupt` is a frontend error.** Taxonomy
`one-handler-per-resource` says *exactly one*; >1 fires `IRQ-ERR-DUPLICATE-HANDLER`, 0 fires a
missing-handler error (ID harness-named, same check family). `Option<Interrupt>` may have a handler;
registration is skipped when the binding is absent (recognition-only this phase per D06). Provenance:
spec-derived (the "exactly one" invariant), not asked. Confidence: high. Surfaces: S08, S02.

**D14 — Preamble ordering: interrupt is last of the resource preambles this slice.** Taxonomy
invariant "ordered after dependent resources (Register Access region, declared protected-state
lock)" ⇒ after BRM's four ops + `map_region` (and after lock init when Synchronization lands). The
ordering facts must be queryable from ONE source by all backends; the representation (lifecycle
synthesis tables vs per-construct preamble registry) is harness-owned (Open O2). Provenance:
spec-derived. Confidence: high. Surfaces: S04.

## Formal Contracts

**C01 — Lifecycle placement & trace contract** (design-intended; D01/D02/D09/D12/D14). Normative
order, rendered as the generic-c golden-trace grammar (linux_c/zephyr_c emit the same order with their
APIs):

```
LC register → LC create → LC associate
→ [bus preamble ops] → [map_region] → IRQ register line=<n>      # line DISABLED (IRQF_NO_AUTOEN / no irq_enable)
→ LC call on_init
   on Ok:  → IRQ enable line=<n>                                  # D02 safe point
   on Err: → (no IRQ enable) → reverse unwind of acquired preambles incl. IRQ unregister
…
teardown (orderly): LC call on_deinit → IRQ disable line=<n> → IRQ unregister line=<n>   # linux: free_irq
                                                            └ zephyr: ABSENT per CAP row (C02); audit artifact at this position
→ [reverse postambles] → LC release
fire semantics (generic-c): regseq_irq_fire on a disabled/unregistered line is inert (traced, assumed spelling O1);
fire on an enabled line invokes the wrapper synchronously → `IRQ result=<Handled|NotHandled>`.
```

**C02 — Capability row, Zephyr static deregister** (design-intended; D03):

```
row_id:            CAP-ZEPHYR-STATICIRQ-DEREGISTER-1        # grammar C02 of the disposition rule; N=1
key:               (target_os=zephyr, os_version_pin="v4.4.0" literal, bus_family=dt,
                    registration_form=static_connect, slot=interrupt.register_handler.deregister)
disposition:       <NEW KIND> operation-structurally-absent-on-registration-form   # name minted at PRD; NOT AbsentDispatch
behavior:          deregister NOT emitted; irq_disable IS emitted at deinit postamble;
                   post-deinit state = handler connected-but-masked (stated in conformance + whitelist)
artifacts (4):     audit comment block at the postamble position · conformance.zephyr.json entry ·
                   RSEQ-CONFORMANCE test-log line · eval trace-whitelist entry citing this row_id
citation:          Zephyr v4.4.0: static IRQ_CONNECT populates _sw_isr_table at build; no disconnect API
                   for static connects (irq_disconnect_dynamic requires CONFIG_DYNAMIC_INTERRUPTS + dynamic connect);
                   stock uart_pl011.c has no shutdown path and never calls irq_disable.
table-domain note: first non-lifecycle-slot row — the table schema widens (PRD work item).
```

**C03 — `[interrupt.<id>]` L2 schema** (design-intended; D05/D08/D10; fixture-witnessed
`platform.toml:21-25`):

```toml
[interrupt.<id>]                  # <id> = the mandatory #[rseq::interrupt(id)] string (D08); one section per resource
irq_number       = <u32>          # line identity, static form; REQUIRED for generic-c/static targets;
                                  # advisory/checked on zephyr (backend emits DT_INST_IRQN(n) macros);
                                  # linux resolves at runtime: AMBA dev->irq[0], PCI pdev->irq (INTx)
trigger_type     = "level" | "edge"                                  # optional; validation-first (D10)
trigger_polarity = "active_high" | "active_low" | "rising" | "falling"  # optional; canonical spellings only
priority         = <u32>          # optional; zephyr IRQ_CONNECT arg; ignored on linux (G-INT-07)
shared           = true | false   # default false; board fact; drives IRQF_SHARED emission (D05)
                                  # and the NotHandled-arm discipline check
# Option<Interrupt>: section may be absent ⇒ None.  [Interrupt; N]: spelling deferred (recognition-only, D06).
```

**C04 — `IrqResult` per-target mapping** (spec-derived arms; design-intended phase column):

```
enum IrqResult { Handled = 0, NotHandled = 1, DeferWork = 2 }    # FrameworkType, discriminants normative
linux_c  : Handled → IRQ_HANDLED · NotHandled → IRQ_NONE (never suppressed) · DeferWork → EmitError this phase (D04)
zephyr_c : value discarded (void ISR convention) · DeferWork → EmitError this phase
generic_c: traced verbatim: `IRQ result=Handled|NotHandled` · DeferWork → EmitError this phase
ISR signature: (&mut self) -> IrqResult, or (&mut self, index: usize) -> IrqResult for array-bind; never Result<_, RegseqError>.
Wrapper recovers driver instance (linux dev_id · zephyr sw_isr_table parameter slot · generic-c ctx ptr); acquires NO locks (D11).
```

**C05 — generic-c hook family** (design-intended; D07):

```c
void regseq_irq_register(uint32_t line, void (*wrapper)(void*), void *ctx);  /* trace: IRQ register line=<n> */
void regseq_irq_enable(uint32_t line);                                       /* trace: IRQ enable line=<n>   */
void regseq_irq_disable(uint32_t line);                                      /* trace: IRQ disable line=<n>  */
void regseq_irq_unregister(uint32_t line);                                   /* trace: IRQ unregister line=<n> */
void regseq_irq_fire(uint32_t line);   /* SYNCHRONOUS; harness-called; inert when disabled/unregistered (O1) */
```

**C06 — Frontend checks & diagnostics** (spec-derived IDs; D06/D08/D13):

```
IRQ-ERR-BARE-ISR-AMBIGUOUS        bare #[rseq::isr] with ≠1 Interrupt resource            error
IRQ-ERR-ARRAY-BIND-NO-INDEX       array-bound handler lacking index: usize                error
IRQ-ERR-DUPLICATE-HANDLER         >1 handler on a non-optional resource                   error
<missing-handler id, O3>          0 handlers on a non-optional resource (D13)             error
<unknown-field id, O3>            isr(field=…) naming a non-Interrupt/unknown field       error
<missing-id id, O3>               #[rseq::interrupt] without id (D08)                     error
IRQ-ERR-EXCLUDED-PRIMITIVE        excluded-set reintroduction (sync-with-handler, trait ISR) error
IRQ-ERR-DRIVER-CALLABLE-LINE-CONTROL  wrapper-method line control on Interrupt            error
shared-line discipline            shared=true without reachable NotHandled arm            warning
DeferWork reachable               (emit stage, D04)                                       EmitError
Option/array lowering reached     (emit stage, D06)                                       EmitError
```
