# PLAN — backend-linux-c (PL011 first-light unit)

## Overview

Implement the `linux_c` backend (independent lowering of `RegseqModel` to an idiomatic
Linux kernel module, per ratified §F.1) and prove it end-to-end on one composed PL011
spec through the L0–L3 validation ladder. Unit merges at PL011 first light (GRILL C01);
merge is the Zephyr-track launch trigger. Source of truth: PRD-2026-06-09-230916
(R01–R12, I01–I06) and GRILL-2026-06-09-225500 (D01–D12, C01–C04, S01–S14).
