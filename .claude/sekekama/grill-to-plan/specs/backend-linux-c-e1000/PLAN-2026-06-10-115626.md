# PLAN — backend-linux-c-e1000 (PCI scaffold, config space, E1000 keystone)

## Overview

Extend the shipped `linux_c` backend along the device-complexity axis: replace the PCI
arm of the bus dispatch with a real PCI scaffold (pci_driver, probe/remove/shutdown,
multi-row `pci_device_id[]`), add managed PCI bus-resource acquisition (enable →
request regions → map BAR0, devres teardown), and activate the existing `emit_config`
seam via per-site `container_of` device-pointer recovery — proven end-to-end on one
composed E1000 fixture (all five built constructs + config ops; an MMIO bring-up
slice, explicitly not a NIC) through the L0–L3 ladder against the QEMU 82540EM,
including the first runtime witness of the errno-adapter error machinery via an
induced-failure variant. Single resolved region (BAR0) this unit; >1 region stays
fail-loud naming B-5. Source of truth: PRD-2026-06-10-114136 (R01–R14, I01–I06) and
GRILL-2026-06-10-113343 (D01–D10, C01–C04, S01–S17, O1–O4). Baseline `b906988`,
2243/0 workspace tests; the parallel Zephyr unit branched from the same point (R14).
