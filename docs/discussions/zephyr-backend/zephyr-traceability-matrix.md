# Zephyr traceability matrix — the consolidated trace

Every construct's trace rows in one matrix, uniform columns:
**model surface · generic_c ref · Zephyr lowering · scaffold point ·
error/lifetime · open decision**. The normative prose behind each row is in
[`zephyr-lowering-per-construct.md`](./zephyr-lowering-per-construct.md); open
decisions are consolidated with recommendations in
[`zephyr-open-questions.md`](./zephyr-open-questions.md) (the `OQ-*`/`O*`/
`Q*`/`ZE-OQ*` labels below are the per-construct local IDs mapped there).

Unless otherwise qualified: paths `body_emit.rs`/`prelude.rs`/`errno.rs`/
`naming.rs`/`mod.rs` are under `crates/regseq-backends/src/generic_c/`;
`domain_attr.rs`/`device_lifecycle.rs`/`target.rs` under
`crates/regseq-model/src/`; `uart_pl011.c`/`uart_pl011_registers.h`/
`arm_pl011.yaml` under `reference-drivers/pl011/zephyr/`; `eth_e1000.c`/
`eth_e1000_priv.h`/`intel,e1000.yaml` under `reference-drivers/e1000/zephyr/`.
