# Linux traceability matrix — consolidated trace rows

Every construct's trace rows in one matrix. Each row is:
**model surface · `generic_c` ref · Linux lowering · scaffold point · error/lifetime
· open decision.** The normative prose for each row is in
[`linux-lowering-per-construct.md`](./linux-lowering-per-construct.md); the
disposition per primitive is in
[`linux-primitive-materialization.md`](./linux-primitive-materialization.md).

Linux cites pin mainline LTS 6.6+ as full pinned URLs
(`https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/plain/<path>?h=v6.6`
for source, `https://docs.kernel.org/<page>.html` for documentation).
Reference-driver cites are repo-relative paths into the vendored authoritative
as-built Linux C under `reference-drivers/{pl011,e1000}/linux/`.
