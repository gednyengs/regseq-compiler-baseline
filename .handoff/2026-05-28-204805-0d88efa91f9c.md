  char <raw>[size]` member on **every** emitted C `union`, via `raw_member_name`

  conditional `_pad` filler; layout-neutral (gnu11 type-pun).

  `Byte::Reloc` fails loud = #2-reloc).

  loud**), replacing the scalar-only multi-view payload write — so a **no-reloc**
  structured enum const payload serializes into the enum `_raw`.
