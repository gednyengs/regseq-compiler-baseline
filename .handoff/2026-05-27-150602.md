## Key decisions & rationale

(Durable list: `docs/discussions/generic-c-backend/decisions-and-state.md`.)

- **"(d) bodies" split into d1 + d2** (user-approved, mirrors c→c1/c2). d1 =
  §15 root-widening + banks 4-5 + §7 envelope + §7.1 terminators + §6/§10/§11/§12/
  §4/§5 value lowering + §16 panic + §17 linkage, for the **scalar/pointer/
  control-flow** subset. **d2** = structured data: `Field`/`Index`/`Downcast`
  place access, `Aggregate`/`Repeat`/`Discriminant` rvalues, `UnaryOp::PtrMetadata`,
  `PointerCoercion::{Unsize,ClosureFnPointer}` + `Ref`-to-unsized (fat-pointer
  construction), `SetDiscriminant` + the §13 enum tag-ops, the
  `Const::{Bytes,Aggregate,EnumValue}` forms. Each d2 construct is already a
  fail-loud `EmitError::Unsupported` arm in d1 — d2 replaces each with real
  lowering. **Diag-log call-site interception + §8 printf + the first green
  ledger fixture = task e** (d1 emits the ordinary/divergent Call + the §15
  bank-4/5 diag-log exclusion; errors on a diag-log call site).
- **Instance C-symbol naming = linkage-aware derived (d1.1, `d040b37`).** The
  bridge mints `emission_name = DefPath.rendered` (generic-agnostic, per-item,
  often not a valid C identifier — e.g. `crate::{extern#0}::foo`). The backend
  **derives** the final symbol: external linkage (`NoMangle`/`export_name`/
  `Foreign`) → `sanitize(emission_name)` **no** generic suffix (ABI-stable across
  monos); internal (`Default`/`Weak`) → `sanitize(emission_name) +
  generic_suffix(generic_args)`, `_clash_<n>`-netted (reserving prelude
  `regseq_*` helpers + external names). **Accepted deviation from the d1.1
  spec:** the spec said "verbatim external"; the implementer found external
  emission_names aren't valid C and chose **sanitise-all + suppress-suffix-on-
  external** instead — sound + better-reasoned (the harness sanitises identically
  on both sides, so `sanitize` is the cross-TU contract; the bridge already
  doesn't preserve the literal `#[no_mangle]` symbol — a separate bridge
  limitation). Pinned in `generic-c-backend.md` §7 (+ §17 vtable-shim note).
- **Soundness-pass discipline paid off** ([[assessment-soundness-pass]]): d1's
  gates were all green; the emission_name hole was invisible to the fixtures and
  only surfaced by a focused Codex pass probing the actual bridge mint sites.
  Apply the same bar to d2 (the §13 tag-ops / aggregate field access touch
  layout invariants).
- **Commit convention:** project commits to `main` directly (single-architect);
  **no author-attribution trailers** (overrides the generic harness default).
  Tasks filed via `uv run python scripts/python/task.py add-task`. Note: a hook
