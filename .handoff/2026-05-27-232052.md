### What d2.2 (`regseq-backends-14`) shipped

All non-scalar `Const` lowering, **sound** under the pinned `cc` flags
(`-std=gnu11 -fwrapv -Wall`, no `-fno-strict-aliasing`). Changes A–G in
`body_emit.rs` + `enum_emit.rs` + `mod.rs` + a bounded §12/§13 `generic-c-backend.md`
Doc delta:
- **A — the enum `_raw` union member**: `unsigned char _raw[size]` on every multi-view
  enum's `union u`; a value-position enum const inits `(struct E){ .u._raw = {bytes} }`
  (the union-of-views can't be const-initialized with separate `_tag`/`_v<v>` members —
  a 2nd C union designator overrides the 1st); runtime reads stay in-place union
  accesses (gnu11 type-punning, sound; layout-neutral). Navigator entry
  `enum_emit::enum_raw_member` (single source of truth).
- **B — the `Const::Bytes` byte-image walker** (`bytes_to_typed_literal`): scalars decode
  per `model.target.endian`; pointers via a `pointer_size` `Byte::Reloc(r)` run →
  `&target`; aggregates slice per `FieldLayout.offset` (source order, ZST omitted);
  arrays via the declarator-aware `types::declare(elem, "[n]")`; enums via
  `.u._raw = {bytes}` (multi-view, no-reloc) / inline. All slicing bounds-checked.
- **C — the reference carrier** (`[Reloc, Uint(meta)]` over `Ty::Ref`): sized → reloc
  designator; `Str`/`Slice` → §3.2 fat struct with `.data` via `slice_data_ptr_type`;
  `dyn` → vtable task.
- **D — the typed valtree aggregate**: `Tuple`/`Struct`/`Closure`/non-`u8` `Array`
  (source-order pairing); enum + `Ty::Union` consumers → reject/d2.3.
- **E — multi-member `Const::EnumValue`**: serialize tag + scalar payload to a
  `layout.size` byte image (`write_bits_into`, endian per target) → `.u._raw = {bytes}`;
  **bool-niche multi-view works** (the niche byte goes in directly; d2.1's discriminant
  read uses raw storage); a reloc/non-scalar payload → d2.3.
- **F — `ConstMemoryStatic` re-typing pre-pass** (`mod.rs`): a deterministic scan recovers
  each CMS's consumer pointee as a backend-local `StorageTy` (`Sized(TyId)` /

## Key decisions & rationale

(Durable list: `docs/discussions/generic-c-backend/decisions-and-state.md` — the d2.2
row + the d2.3 entry are now recorded there.)

- **The d2.2 design (the two validated primitives).** The FIRST draft (synthesised
  packed struct for reloc-bearing CMS + union-member designators for enum consts) had
  TWO architectural soundness holes Codex caught: (1) the §13 union-of-views can't be
  const-initialized with separate tag + payload (a 2nd C union designator overrides the
  1st); (2) a non-char CMS read through `(const T*)&X` is strict-aliasing UB. Fixed via
  **the `_raw` union member** (Change A) + **CMS re-typing by consumer pointee** (Change
  F). The `_raw` gnu11 type-pun is sound **only because runtime reads stay in-place
  through the union** (never inactive-member-address-then-deref). CMS re-typing uses a
  **backend-local `StorageTy`**, not a model `TyId` (the bridge interns `Slice(elem)` but
  not `Array(elem, meta)`; the array case spells via the declarator-aware
  `types::declare(elem, "<ident>[<count>]")`).
- **The post-close soundness fix — `place_ty` as the single source of truth.** The scan
  MUST narrow the assignment destination the SAME way the body emitter lowers the const
  against (`place_walk`); a shortcut that gives up on non-`Field` projections silently
  miscompiles. The fix factors the §19.4 narrowing into one shared free function. This
  is the generalised d2/d2.1 "shared walk / single source of truth" lesson, applied to
  the scan-vs-emit boundary.
- **Soundness-pass discipline pays off a 4th time** ([[assessment-soundness-pass]]). d1
  green → bug; d2 green → bug; d2.1 green → bug; **d2.2 green (163 fixtures) → bug.** The
  mandatory pass is codified in each task's Quality Gate; keep it for e + d2.3.
- **task e likely takes priority over d2.3.** e (the first green coverage-ledger fixture)
  only needs d2.2's `&str` carrier + `u8` CMS, both shipped; d2.3's five carve-outs are
  rare. Confirm ordering with the architect.
