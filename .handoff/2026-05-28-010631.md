### What task e (`regseq-backends-15`) specs — Changes A–G

A three-piece bundle: **(1) backend §8 lowering** (A–D), **(2) harness bring-up** (E–F),
**(3) the first fixture corpus** (G).

- **A — call-site interception** (`body_emit.rs` `call`, replace the `:1797` fail-loud):
  `Direct(inst)` + `model.instance_intrinsic(*inst) == Some(Log(level))` → emit §8 printf,
  `goto bb_<target>`, no dest assignment (unit); `None` target → fail loud; Pipeline-A
  (read flat peeled args, NO `LogArg` reconstruction); placeholder count == `args.len()-1`.
- **B — the §26.7-subset format-template parser + the `args[0]` CMS-bytes reader.** The
  backend depends only on `regseq-model` (NOT the driver) and the model carries no parsed
  template, so it re-derives: read the template text from `args[0]`'s
  `Aggregate([Reloc→CMS, Uint(len)])` → `Const::Bytes` → UTF-8 (via `model.consts` +
  `resolve_reloc`, mirroring `peel.rs:191-227` but NOT the bridge cache); parse the
  **bridge's actual** accepted set — the 8 hex forms `{x,X}`×`{plain,#,08,#010}` (incl.
  uppercase-padded `:08X`/`:#010X`) via a `{upper, alternate, width}` tuple, `{{`/`}}`,
  embedded `\n`, empty; malformed brace / out-of-subset → `Unsupported`.
- **C — the (Modifier, Ty) → (specifier, CAST) mapping**, **reusing `body_emit::printf_spec`
  (`:1941-1957`) BEHIND a §26.4-admissible whitelist** (printf_spec is broader — also
  Char/Isize/Usize → reject those). The `ll` length modifier is mandatory for 64-bit hex
  AND every numeric arg is cast; **signed hex uses the two-step source-width cast**
  (`i8→(unsigned)(uint8_t)` so `-1i8`→`ff` not `ffffffff`; `i16→(unsigned)(uint16_t)`;
  `i64→(unsigned long long)`).
- **D — printf emission + the C-string escaper + the §8.3 `&str` strategies.** Format =
  `[LEVEL] ` ++ interleave(C-escaped literals with literal `%`→`%%`, specifiers) ++ `\n`;
  every numeric arg wrapped in its Change-C cast; **static-literal `&str`** → direct C
  string literal from the CMS bytes; **non-static `&str`** → per-`%s`-site independent
  stack buffer (cap 256, `min(len, cap-1)` memcpy, NUL at `min(len,cap-1)`, no marker, no
  over-read); the static/non-static split = the operand form (Constant-carrier vs place).
- **E — activate the inert `--bless`** (`main.rs:108-117`): write **only `golden.c`** from
  the stage-2 emit, report-mode stages 4–6; **never** writes `expected.stdout` (the
  behavioral oracle stays hand-authored — no self-certify); non-bless run unchanged.
- **F — fix the entry-symbol gap** (`pipeline.rs:142`): it passes `manifest.entry`
  verbatim, but the backend emits the entry as `sanitize(emission_name)` (e.g.
  `crate::regseq_main`→`crate_regseq_main`). Resolve+sanitize from the model mirroring the
  in-crate `fn_cname` (`generic_c_bodies.rs:69-100`); expose `naming::sanitize` (currently
  `pub(crate)`). **task e is the first on-disk fixture ever, so it's the first to hit
  this.** ([[codegen-runner-entry-symbol-gap]])
- **G — the first `kind="rust"` on-disk fixtures** (`crates/codegen-coverage-runner/fixtures/<name>/`):
  per-level, numeric widths, bool, hex (incl. uppercase-padded + signed at every width),
  static & non-static `&str`, ≥256-byte truncation, empty template, escapes, embedded
  newline. Each = self-contained `#![no_std]` log prelude (extends the `diag_log_common.rs`
  SHAPE with a `LogArg` variant + `From` per type it logs) + `#[no_mangle] regseq_main`;
  blessed `golden.c` + hand-authored `expected.stdout`; "log a computed value". Flips

## Key decisions & rationale

(Durable list: `docs/discussions/generic-c-backend/decisions-and-state.md`. Per-task
drafting progress is NOT tracked there — that's this handoff.)

- **"Full §8 in one task" (architect choice).** The non-static `&str` stack buffer +
  truncation is a separable chunk, but the architect chose to land the complete diag-log
  domain at once (DL-4 fully green; no diag-log follow-up). The 3 pieces stay bundled
  because "first green fixture" is one milestone (you can't verify the lowering green
  without the harness bring-up + fixtures).
- **The backend needs its OWN format-template parser.** `regseq-backends` depends only on
  `regseq-model`, not the driver; the model carries no parsed template (the fingerprint is
  transient, §26.6). So the backend re-parses the §26.7 grammar — confirmed the expected
  design ("the backend re-derives the same information from the IR").
- **printf varargs need value CASTS, not just matching format text** (Codex R1, REAL bug).
  Reuse the existing `printf_spec` helper, but **behind a §26.4-admissible whitelist** (R2
  — printf_spec is broader). Signed hex needs the **two-step source-width cast** (R2 — a
  flat `(unsigned)` sign-extends `-1i8` to `ffffffff`). This is the generalised "single
  source of truth + correctness-at-the-emit-boundary" lesson applied to varargs.
- **`--bless` writes ONLY `golden.c`, never `expected.stdout`.** The snapshot oracle is
  blessed-from-emit + human-reviewed; the behavioral oracle is hand-authored (the expected
  *computed* value) so a miscompute can't self-certify (Doc-3 §2 "never auto-blesses").
- **Two findings surfaced (both real, both grounded against HEAD):**
  1. **The entry-symbol gap** — saved to project memory [[codegen-runner-entry-symbol-gap]];
     Change F fixes it. Blocks EVERY on-disk fixture, not just diag-log.
  2. **The §26.7-vs-bridge hex drift** — the bridge accepts uppercase-padded `:08X`/`:#010X`
     beyond §26.7's "closed leading set". task e handles the bridge's actual output + FLAGS
     the reconciliation (widen §26.7's table OR tighten the bridge) as a **separate,
     unresolved** question (NOT task e's job). See Open questions.
- **Soundness-pass discipline pays off again** ([[assessment-soundness-pass]]). Even at the
  SPEC stage, 3 Codex rounds caught a varargs-cast soundness hole + a parser-coverage gap
  the prose hid. The mandatory POST-CLOSE soundness pass (the 5th, after d1/d2/d2.1/d2.2)
  is codified in task e's Quality Gate — keep it for the implementer's close.
