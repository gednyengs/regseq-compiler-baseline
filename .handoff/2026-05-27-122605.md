## Key decisions & rationale

(Durable decisions: `docs/discussions/generic-c-backend/decisions-and-state.md`.)

- **Split "(d) bodies" → d1 + d2** (user chose this via AskUserQuestion). The
  surface (terminators + rvalues + casts + consts + places + intrinsics + §13
  tag-ops + banks 4-5 + root-widening) is too large for one task; the natural seam
  is "scalar SSA + CFG, no aggregate construction/projection" (d1) vs "structured
  data" (d2). d1 alone unblocks task e's first green fixture (a diag-log of a
  *computed scalar* value needs no field access / enums / aggregates).
- **d1 fixes a latent c1 discovery gap (Codex R1 #1).** `containment_target`
  returns `None` for sized `Ref`/`Ptr` (`mod.rs:236`), and the nominal-root net
  (`bridge/mod.rs:2375`) names only *nominal* aggregates behind a pointer — so a
  *structural* tuple/closure behind a pointer (e.g. a `&(u8,u32)` param) would
  panic the `NameTable`. d1 adds an explicit **discovery-vs-ordering split** (A2):
  follow sized pointer edges in **discovery only** (naming/forward-decl, recursive,
  no ordering edge → no false `ContainmentCycle`); `ordering_edges`/`topo_sort`
  unchanged. The "no new ordering edge" is sound because **bank 3 < banks 4/5**
  structurally covers by-value param/return/local completeness.
- **`Const::Reloc` is Function/Static targets only** (Codex R1 #5), per the
  bridge-validated §10.1.7 invariant the sibling pretty-printer encodes
  (`pretty.rs:1147-1228`). Address-taken consts surface as synthetic
  `ConstMemoryStatic` *statics* with `Bytes` inits → a `Reloc` to one is
  structurally `Reloc`-to-Static, but that static's own `Bytes` init fails loud
  (d2). No separate Reloc d1/d2 split needed.
- **Other Codex R1 fixes:** nested `FnPtr` C-ABI recursion in `fn_ptr_decl` (§15
  line 1080); portable `Assume` = `if (!x) __builtin_unreachable();` (both
  gcc+clang; `__builtin_assume` is clang-only); `InvalidEnumConstruction(v)` is
  operand-bearing (carries `<v>`, `terminator.rs:173`); verification uses the
  existing `void regseq_main` contract (no harness change).
- **Commit convention:** project commits to `main` directly (single-architect),
  **no author-attribution trailers** (per `.harness/generic-c/methodology.md` /
  global CLAUDE.md §1.3) — overrides the generic harness Co-Authored-By default.
