### The two soundness bugs fixed this session (`19f5b25`)

1. **Nested array `Subslice` under a `Ref` lost the inner `from` offset** (REAL
   correctness bug). `PlaceWalk` didn't expose `place_walk`'s accumulated
   `pending_from`; `subslice_ref` re-walked the base and applied only the final
   `from`. `&_1[1..5][1..3]` emitted `&_1[1]`, should be `&_1[2]`. Fix: `PlaceWalk`
   carries `pending_from`; `subslice_ref` uses `effective_from = base.pending_from +
   from`. Regression test `nested_array_subslice_under_ref_accumulates_offsets`.
2. **Thin `RawPtr` aggregate dropped its metadata operand unchecked** (fail-loud
   gap). A deferred const in the metadata slot was silently accepted. Fix: lower
   (validate) `ops[1]` before dropping, matching the `Call` lower-then-drop idiom.
   Regression test `thin_raw_ptr_aggregate_lowers_metadata_before_dropping_it`.

## Key decisions & rationale

(Durable list: `docs/discussions/generic-c-backend/decisions-and-state.md`.)

- **"(d) bodies" → d1 + d2, and d2 → d2.1 / d2.2 / vtable** (user-approved
  2026-05-27, mirrors c→c1/c2). d2 = non-enum, non-const structured data. **d2.1** =
  §13 enum tag-ops (`Downcast`/`Discriminant`/`SetDiscriminant`/`Aggregate::Enum`/
  `EnumValue`) — the layout-invariant set, gets its own soundness pass. **d2.2** =
  ALL non-scalar const: the bridge emits these as `Const::Bytes` flat byte-images
  (often relocation-bearing, e.g. `[fn();2]`) + the `Const::Aggregate([Reloc,Uint])`
  reference carrier whose `Reloc`→`ConstMemoryStatic` is itself a `Bytes` static — so
  the carrier is **transitively coupled** to byte-image lowering and can't be split
  from it (this coupling is why d2 has zero const work). **vtable task** =
  `dyn`/`Unsize`-to-dyn/`ClosureFnPointer`/vtable/dispatch. Each deferral is a
  distinct fail-loud `EmitError::Unsupported` label so each later task replaces only
  its own arms.
- **Backend reuses its OWN place narrowing, not `regseq_model::place_ty`** —
  `unwrap_recovered` is `#[cfg(test)]` and the model's array-`Subslice` recovery is
  conditional on the shortened array being interned. The backend's `place_walk` is a
  single shared walk (lvalue + type together, so they can't drift) mirroring the
  §19.4 table.
- **Fat-pointer `Deref` = `.data` slot, not `(*p)`** (a d1 latent gap d2 closed):
  thin `Deref` → `(*p)`; fat (slice/str) `Deref` → `lv.data`, remembering the fat
  base for a `from_end` index / `.len`. `dyn` `Deref` → vtable task.
- **Soundness-pass discipline keeps paying off** ([[assessment-soundness-pass]]):
  d2's gates were ALL green (incl. compile-and-run), yet the focused Codex pass found
  two holes the fixtures never exercised. Apply the same bar to d2.1 (the §13 tag-ops
  touch layout invariants — highest-risk yet).
- **Commit convention:** project commits to `main` directly (single-architect); **no
  author-attribution trailers** (overrides the generic harness default). Tasks filed
